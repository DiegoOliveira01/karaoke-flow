      Palavras sincronizadas

      Marca o tempo de cada palavra usando a voz isolada do cantor e a letra sincronizada. Na tela de karaokê, cada palavra é preenchida no momento em que é cantada.

      Roda uma vez por letra, na GPU, e pode levar alguns minutos. Enquanto isso (ou se alguma linha não der certo) a tela usa o preenchimento estimado por linha. Trocar a letra descarta as palavras.

        Como usar
        1. Dê play (tecla P). Use 0,5× se estiver difícil acompanhar.
        2. Segure Espaço (ou o botão grande) enquanto a palavra marcada é cantada e solte quando ela termina. Um toque rápido também vale: a palavra dura até a próxima.
        3. Errou? Clique na palavra (ou use as setas) e marque de novo. Tocar daqui volta a música para antes da linha.
        4. Ouvir linha mostra como ficou. O ajuste fino corrige em centésimos de segundo.
        5. Linhas que você não completar continuam com o preenchimento estimado. Depois é só Salvar.
